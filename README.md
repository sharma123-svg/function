# JavaScript Counter

A small beginner-friendly JavaScript project built with plain HTML, CSS, and JavaScript.

## Run the project

1. Open `index.html` in a web browser.
2. Click `+`, `−`, or `Reset`.

## What each file does

- `index.html` creates the page structure.
- `style.css` controls the appearance.
- `script.js` stores the counter value and responds to button clicks.
